# Инструмент конфигурационного управления

## 1. Общее описание

Данный проект представляет собой инструмент командной строки для преобразования текста конфигурации на учебном конфигурационном языке в формат XML. Инструмент читает описание конфигурации из стандартного ввода (stdin), обрабатывает его и записывает результат в указанный выходной файл.

Основные возможности:
- Поддержка однострочных и многострочных комментариев.
- Объявление и использование констант.
- Работа с массивами и словарями.
- Вычисление константных выражений (сложение, вычитание, возведение в степень).
- Поддержка чисел в двоичной системе счисления.

## 2. Описание функций и настроек

### Синтаксис конфигурационного языка

#### Комментарии
- **Однострочные:** Начинаются с символа `"` и продолжаются до конца строки.
  ```
  " Это однострочный комментарий
  ```
- **Многострочные:** Заключаются в теги `<#` и `#>`
  ```
  <#
    Это многострочный
    комментарий
  #>
  ```

#### Типы данных
- **Числа:** Записываются только в двоичной форме с префиксом `0b`.
  Пример: `0b101` (число 5).
- **Массивы:** Объявляются с помощью ключевого слова `array`.
  Пример: `array(0b1, 0b10, 0b11)`
- **Словари:** Объявляются с помощью конструкции `@{ ... }`. Элементы разделяются точкой с запятой.
  Пример:
  ```
  @{
    key1 = 0b1;
    key2 = 0b10;
  }
  ```

#### Константы
Объявление константы производится с помощью ключевого слова `var`.
Синтаксис: `var имя := значение;`
Пример:
```
var base_value := 0b1010;
```
Использование константы происходит по её имени.

#### Вычисления
Выражения для вычисления заключаются в вертикальные черты `| ... |`.
Поддерживаемые операции:
- Сложение: `+`
- Вычитание: `-`
- Возведение в степень: `pow(основание, степень)`

Пример:
```
|base_value + 0b10|
|pow(0b10, 0b11)|
```

### Аргументы командной строки

Запуск программы осуществляется через интерпретатор Python.

Параметры:
- `-o`, `--output`: Путь к выходному файлу для сохранения результата в формате XML (обязательный параметр).

## 3. Описание команд для сборки проекта и запуска тестов

### Требования
Для работы программы необходим **Python 3**. Дополнительные библиотеки не требуются (используются только стандартные модули).

### Запуск программы
Программа читает данные из стандартного ввода. Для запуска используйте перенаправление ввода:

**Windows (PowerShell):**
```powershell
Get-Content tests/game_settings.txt | python main.py -o output.xml
```
или
```powershell
python main.py -o output.xml < tests/game_settings.txt
```
*(Примечание: в PowerShell `<` может требовать настройки, надежнее использовать `Get-Content ... | python ...`)*

**Linux / macOS:**
```bash
python3 main.py -o output.xml < tests/game_settings.txt
```

### Запуск тестов
В папке `tests/` находятся примеры конфигурационных файлов.
- `game_settings.txt` — пример корректной конфигурации.
- `error_lex.txt` — пример с лексической ошибкой.
- `error_syntax.txt` — пример с синтаксической ошибкой.

Для проверки работоспособности можно запустить обработку тестового файла:

```bash
python main.py -o result.xml < tests/game_settings.txt
```

После выполнения в файле `result.xml` должен появиться корректный XML.

## 4. Примеры использования

### Входной файл (input.txt)
```plaintext
<# Пример конфигурации #>
var val := 0b1010; " 10

@{
  settings = @{
    width = 0b1100100;
    sum = |val + 0b10|;
  };
  items = array(0b1, 0b0);
}
```

### Команда запуска
```bash
python main.py -o config.xml < input.txt
```

### Результат (config.xml)
```xml
<?xml version="1.0" ?>
<config>
  <settings>
    <width>100</width>
    <sum>12</sum>
  </settings>
  <items>
    <item>1</item>
    <item>0</item>
  </items>
</config>
```
